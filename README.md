## 📋 About This Project

This is a static HTML landing page built as a student learning hub for **CDAN 2314 Asset Development** — a course focused on the technical pipeline for developing environment assets optimised for real-time engine deployment.

The hub covers:

- Course announcements and important dates
- Course learning outcomes (CLOs), assessment breakdown, and reading list
- 14 weeks of topic content with pro tips from the teaching plan
- YouTube tutorial videos from **2025–2026** for each weekly topic
- Switchable learning path between **Unreal Engine 5** and **Unity Engine**
- Quick-access links to documentation, asset stores, and learning portals
