Course Information
📖 Synopsis +
This course provides a comprehensive deep dive into the technical pipeline for developing environment assets optimised for real-time engine deployment. Students will master the transition from base block-outs to high-fidelity implementation, focusing on maintaining visual parity while adhering to real-time performance constraints. The curriculum emphasises the technical logic behind realistic environment design and the implementation of collaborative-friendly workflows within an actual production team.
🎯 Course Learning Outcomes (CLOs) +
CLO 1Demonstrate proficiency in scene set dressing in a real-time engine application (P3, PLO5)
CLO 2Implement advanced techniques such as modular asset creation, material blending, and level streaming to optimise environment asset creation workflow (P3, PLO3)
CLO 3Prepare 3D assets for commercial viability in digital marketplaces (C3, PLO7)
